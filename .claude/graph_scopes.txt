# Microsoft Graph 요청 스코프
#
# 로그인할 때 토큰에 담길 권한 목록이다. 한 줄에 하나씩.
# `#` 로 시작하는 줄은 무시된다.
#
# ── 반드시 알아야 할 것 ────────────────────────────────────────────────
#
# Entra 에 **동의된 권한**과 여기 적은 **요청 스코프**는 별개다.
#
#   동의는 있는데 여기 없다  →  토큰에 안 담긴다. 그 기능이 조용히 안 된다
#   여기는 있는데 동의가 없다 →  로그인 자체가 실패한다
#
# 즉 관리자가 승인해도 이 파일에 줄을 추가하지 않으면 아무것도 달라지지 않는다.
# 반대로 승인 목록에 없는 줄을 남겨두면 첫 로그인부터 막힌다.
#
# 줄을 고친 뒤에는 반드시 재로그인한다.
#
#   python3 bin/graph login --check
#
# ── 이 목록의 근거 ──────────────────────────────────────────────────────
#
# 2026-09-03 현대차 ICT 가 승인한 `HMG-LeaderAXSession-PILOT` 앱의
# API 사용 권한 화면(위임됨 19종, 관리자 동의 완료)을 그대로 옮긴 것이다.
# 원본: source/ict/2026-09-03_Graph권한_승인결과.md
