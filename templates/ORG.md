# ORG.md, 본부 조직, 이해관계자, 과제

- 상태: 미완료
- 최종 갱신: (미갱신)

**0단계에서 AX 챔피언이 초안을 채운다.** 본부장에게 조직도를 받아쓰게 하지
않는다. 챔피언이 알 수 있는 것으로 본부장의 세션 시간을 쓰지 않는다.

이후에는 회의, 메일에서 처음 나온 인물과 과제를 에이전트가 계속 추가한다.
`PROFILE.md` 가 "본부장은 누구인가"라면 이 파일은 "본부장 주위에 무엇이
있는가"다.

## 4. 진행 중 과제

회의 중 추적 대상이다 (`ROUTINES.md` R6). 상태가 바뀔 때마다 갱신한다.

| 과제 | 담당 | 현재 상태 | 다음 마일스톤 | 리스크 | 최종 확인 |
| --- | --- | --- | --- | --- | --- |
| | | | | | |

**상태 값**: `기획` / `진행` / `지연` / `보류` / `완료`
**지연 판정**: 마일스톤 날짜가 지났는데 상태 갱신이 없으면 지연으로 본다.
지연은 조용히 넘어가지 않고 브리핑에 올린다.
